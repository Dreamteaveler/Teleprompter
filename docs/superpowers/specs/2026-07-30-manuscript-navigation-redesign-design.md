# 文稿界面两级导航设计

## 目标

将文稿界面顶部重新划分为“全局操作”和“当前文稿视图操作”两级，降低新增导入、文件夹和批量整理功能后产生的拥挤感，并确保默认窗口与最小宽度下都不换行、不出现水平滚动。

设计重点：

- 第一层只保留应用身份和全局创建入口；
- 第二层承载当前目录、搜索和整理操作；
- 整理模式复用第二层空间，不再额外增加第三条操作栏；
- 保留现有拖放导入、搜索过滤、文件夹导航和批量操作语义。

## 非目标

- 不改变文稿卡片和文件夹卡片的内容结构；
- 不增加左侧边栏、排序器或视图切换器；
- 不改变导入、新建稿件、新建文件夹的业务流程；
- 不改变批量移动、批量删除和搜索过滤的数据库逻辑；
- 不重新设计编辑器或提词器播放界面。

## 信息架构

### 第一层：全局导航

第一层固定展示：

- 左侧：“提词器”应用标题；
- 右侧：“新建稿件”主按钮；
- 右侧：“导入文件”次级按钮。

“新建稿件”是唯一强调按钮。“导入文件”使用次级样式，因为用户还可以通过拖放文件或文件夹完成导入。

第一层不再放置搜索、文件夹或批量管理操作。它在文稿页内保持稳定，避免当前目录状态影响全局入口的位置。

### 第二层：文稿工具栏

普通状态从左到右展示：

- 可点击的目录路径；
- 可伸缩的稿件搜索框；
- “新建文件夹”按钮；
- “整理稿件”按钮。

根目录显示“全部稿件”。进入文件夹后显示可点击路径，例如：

`全部稿件 › 项目文件夹 › 子文件夹`

点击任意路径节点进入对应目录。当前节点使用正文强调色，上级节点使用次级文字色并提供悬停反馈。

## 整理模式

点击“整理稿件”后，第二层原位切换为整理工具栏，不新增第三层：

- 左侧保留当前目录路径；
- 显示“全选当前列表”复选框；
- 显示“已选 N 项”；
- 右侧显示“移入文件夹”“删除”“完成”。

“移入文件夹”和“删除”在没有选中稿件时禁用。“删除”继续使用危险操作样式并保留二次确认。

点击“完成”或按 `Esc` 退出整理模式并清空选择。切换目录时沿用现有行为：退出整理模式并清空选择。

### 搜索状态

进入整理模式时保留当前搜索条件和过滤结果，批量选择仍只作用于当前可见稿件。

如果搜索框中存在内容，整理工具栏在目录路径旁显示简短筛选提示：

`筛选：“关键词”`

该提示用于避免搜索框隐藏后用户误以为正在操作整个目录。退出整理模式后恢复原搜索框及原搜索内容。

## 布局与尺寸

### 第一层

- 高度：64 像素；
- 左右内边距：24 像素；
- 操作间距：8 像素；
- 应用标题保持当前 18 像素粗体层级。

### 第二层

- 高度：52 像素；
- 左右内边距：40 像素，在较窄窗口下降为 24 像素；
- 控件间距：8 像素；
- 使用底部分隔线区分导航和内容，不增加阴影；
- 搜索框优先占用剩余空间，理想宽度为 320 像素，最小宽度为 180 像素。

内容区原有“全部稿件”标题不再重复显示目录名称，只保留稿件数量或状态说明，避免与第二层路径形成重复标题。

## 窄窗口规则

应用最小宽度为 960 像素，两个导航层均保持单行：

1. 第二层搜索框先从理想宽度收缩到最小宽度；
2. 第二层左右内边距从 40 像素收缩到 24 像素；
3. 按钮文字和顺序保持不变，不换行、不裁切；
4. 整理模式隐藏普通搜索框和“新建文件夹”，因此操作区仍能完整容纳；
5. 不使用水平滚动条。

## 视觉规范

- 移除按钮文本中的 emoji，使用纯文字，减少不同系统字体带来的视觉不一致；
- “新建稿件”使用强调色；
- “导入文件”“新建文件夹”“整理稿件”和“完成”使用统一次级按钮样式；
- “删除”只在整理模式中使用危险色；
- 路径、筛选提示、选择数量建立明确的正文、次级和弱化三级文字层级；
- 所有可点击控件保留指针光标、悬停、按下、禁用和键盘焦点状态。

## 状态流转

### 普通状态

1. 用户通过路径切换目录；
2. 搜索框即时过滤当前目录中的稿件；
3. “新建文件夹”在当前目录创建文件夹；
4. “整理稿件”进入整理模式；
5. 第一层的新建和导入操作始终可用。

### 整理状态

1. 第二层隐藏普通搜索框和普通操作；
2. 稿件卡片显示选择框；
3. 全选仅覆盖当前过滤结果；
4. 移动或删除成功后沿用现有搜索条件刷新当前列表；
5. 完成、按 `Esc` 或切换目录时退出整理模式。

## 代码结构

### `HomePage`

负责：

- 将当前单层页头拆为全局导航和文稿工具栏；
- 根据窗口宽度调整第二层内边距和搜索框宽度；
- 在普通工具栏与整理工具栏之间切换；
- 更新目录路径、搜索筛选提示、选择数量和按钮状态；
- 删除内容区重复的目录标题。

### `BatchActionBar`

现有批量操作栏改为可嵌入第二层工具栏的内容组件：

- 不再作为独立第三行加入页面主布局；
- 保留全选、计数、移动、删除和退出信号；
- “退出批量管理”文案改为“完成”；
- 接受当前路径与可选筛选提示，或由 `HomePage` 在其外层统一组合。

优先选择最少职责变更的实现：如果复用现有组件会产生重复容器和样式，则将第二层封装为一个在普通/整理状态间切换的专用工具栏组件。

## 异常与边界

- 根目录路径只有“全部稿件”，不显示多余分隔符；
- 很长的文件夹名称使用省略号，保留首个“全部稿件”和当前目录；
- 搜索结果为空时仍可退出整理模式，但移动和删除保持禁用；
- 进入整理模式前的搜索词不得被清空；
- 批量操作完成后不得丢失搜索过滤状态；
- 路径切换会清空选择，防止操作不可见稿件；
- 拖放覆盖层仍覆盖完整文稿页，不受两级导航影响。

## 测试与验收

离屏 Qt 界面测试覆盖：

- 第一层只包含应用标题、新建稿件和导入文件；
- 第二层普通状态包含路径、搜索、新建文件夹和整理稿件；
- 根目录与多级目录路径显示、点击和当前节点状态正确；
- 进入整理模式后不出现第三条操作栏；
- 整理状态包含全选、选择数量、移动、删除和完成；
- 有搜索词时显示筛选提示，退出后搜索内容仍然存在；
- 批量移动和删除后搜索过滤仍然生效；
- 960、1280 像素宽度下导航不换行、不产生水平滚动；
- `Esc`、完成按钮和目录切换均能正确清理整理状态。

回归验证覆盖：

- 拖放及文件对话框导入；
- 新建稿件和新建文件夹；
- 普通卡片播放、编辑和删除；
- 批量移动与删除；
- 文件夹递归删除；
- Python 编译检查和现有完整测试集。
