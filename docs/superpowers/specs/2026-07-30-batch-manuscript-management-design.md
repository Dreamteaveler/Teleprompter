# 讲稿批量管理设计

## 目标

在讲稿管理界面增加显式的批量管理模式，让用户可以在当前可见列表中选择多篇讲稿，并一次性：

- 移动到现有文件夹或根目录；
- 在选择目标时新建文件夹并立即移动；
- 永久删除。

这里的“整理”是移动讲稿所属文件夹，不引入归档状态或归档页面。

## 非目标

- 不允许选择文件夹；
- 不跨文件夹、面包屑层级或搜索条件保留选择；
- 不重构为 Qt Model/View；
- 不增加回收站、软删除或撤销机制；
- 不改变普通模式下的播放、编辑和单篇删除行为。

## 界面与交互

### 进入和退出批量模式

页面顶部增加“批量管理”按钮。点击后：

- 每张讲稿卡片左上角显示复选框；
- 点击复选框或卡片空白区域均可切换选择状态；
- 选中卡片使用金色边框和轻微高亮；
- 卡片上的“编辑”和“删除”按钮隐藏；
- 文件夹卡片保持可见，但不参与选择；
- 显示批量操作栏。

批量操作栏包含：

- “全选当前列表”复选框；
- “已选择 N 篇”计数；
- “移动到文件夹”按钮；
- “删除”按钮；
- “退出批量管理”按钮。

没有选中讲稿时，“移动到文件夹”和“删除”按钮禁用。全选只覆盖当前界面可见的讲稿，不包含文件夹或被搜索条件隐藏的讲稿。

切换文件夹、点击面包屑、改变搜索条件或按 `Esc` 时退出批量模式并清空选择。普通模式保留现有的卡片点击播放、编辑和单篇删除行为。

### 目标文件夹窗口

点击“移动到文件夹”后打开模态窗口。窗口使用树形结构展示：

- “全部稿件（根目录）”；
- 根目录下的文件夹；
- 任意层级的子文件夹。

根目录是合法目标。确认按钮仅在存在有效目标时可用。

窗口提供“新建文件夹”操作：

- 当前选中具体文件夹时，在其下创建；
- 选中根目录或尚未选择具体文件夹时，在根目录创建；
- 创建成功后刷新树并自动选中新文件夹；
- 空名称不创建；
- 创建失败时窗口保持打开并显示错误。

关闭窗口或取消操作不会移动任何讲稿。

### 批量移动

确认目标后，将当前选择的讲稿 ID 快照交给数据库层。数据库在单个事务中更新讲稿的 `parent_folder_id`：

- 已经位于目标文件夹的讲稿不重复更新；
- 其余讲稿全部成功后统一提交；
- 任意错误导致整批回滚；
- 返回实际移动数量。

成功后退出批量模式、刷新页面并显示实际移动数量。失败时保留选择并显示错误，允许重试。

### 批量删除

点击“删除”后显示二次确认：

- 展示选中总数；
- 最多展示前 5 个讲稿标题；
- 超过 5 个时显示“另有 N 篇”；
- 明确提示永久删除且不可撤销。

确认后在单个事务中删除仍然存在的选中讲稿，并返回实际删除数量。成功后退出批量模式并刷新；失败时整批回滚、保留选择并显示错误。操作前已经不存在的 ID 不导致整批失败。

## 代码结构

### `HomePage`

负责：

- `batch_mode` 状态；
- `selected_manuscript_ids: set[int]`；
- 当前可见讲稿 ID；
- 进入、退出、全选、移动和删除的流程编排；
- 文件夹或搜索条件改变时清理批量状态。

### `ManuscriptCard`

扩展现有卡片，负责：

- 显示或隐藏复选框；
- 根据选中状态应用样式；
- 在批量模式下发出选择切换信号；
- 在普通模式下保持原有播放、编辑和单篇删除信号。

### `BatchActionBar`

新增独立组件，负责：

- 全选状态；
- 已选数量；
- 移动、删除和退出按钮；
- 根据选择数量启用或禁用操作。

组件只发出用户意图信号，不直接访问数据库。

### `FolderPickerDialog`

新增独立组件，负责：

- 构建完整文件夹树；
- 表示根目录目标；
- 返回选中的目标文件夹 ID 或 `None`；
- 在当前选中节点下新建文件夹。

### 数据库层

新增：

- `move_manuscripts(manuscript_ids, target_folder_id) -> int`
- `delete_manuscripts(manuscript_ids) -> int`

两个函数都：

- 接受任意可迭代 ID，并去重；
- 空 ID 集合直接返回 `0`；
- 使用参数化 SQL；
- 在一次事务中完成；
- 返回实际变更行数；
- 异常时由连接上下文统一回滚。

现有单篇移动和删除函数保持兼容。

## 数据流

1. 用户进入批量模式。
2. 卡片发出选择切换信号。
3. `HomePage` 更新选中 ID 集合。
4. `BatchActionBar` 根据集合大小更新计数和按钮状态。
5. 用户选择移动或删除。
6. `HomePage` 获取当前选择快照并完成确认流程。
7. 数据库批量函数在事务内执行。
8. 成功后退出批量模式并刷新；失败则保留选择并提示。

## 异常与边界

- 无选择时不能触发移动或删除；
- 无效目标文件夹由外键约束拒绝，整批移动回滚；
- 已在目标文件夹的讲稿不更新 `updated_at`；
- 数据库返回实际处理数量，界面不假设所有 ID 仍存在；
- 新建文件夹名称去除首尾空白；
- 批量模式重新渲染卡片时保持当前可见选择；
- 离开当前视图时必须清空选择，避免隐藏项目被操作；
- 文件夹不进入选择集合。

## 测试

数据库测试使用隔离的临时 SQLite 数据库，覆盖：

- 多篇讲稿移动到普通文件夹；
- 移动到子文件夹；
- 移动回根目录；
- 已在目标文件夹的讲稿不计入实际移动数量；
- 目标文件夹无效时全部回滚；
- 批量删除只删除选中讲稿；
- 不存在的讲稿 ID 不影响其余有效 ID；
- 空 ID 集合不修改数据。

界面测试使用离屏 Qt，覆盖：

- 进入和退出批量模式；
- 卡片复选框与卡片点击切换选择；
- 全选仅覆盖当前可见讲稿；
- 无选择时批量按钮禁用；
- 搜索或目录变化清空选择；
- 文件夹选择窗口能创建并选中新文件夹。

回归验证包括现有字体策略、单篇删除和递归删除文件夹测试，以及 Python 编译检查。README 的稿件管理功能说明同步增加批量整理能力。
